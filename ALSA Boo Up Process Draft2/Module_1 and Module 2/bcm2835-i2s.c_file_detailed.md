# 1️⃣ File का Overall Role (ALSA Architecture में)

यह driver **ASoC (ALSA System on Chip)** का **CPU-DAI driver** है।

Audio path roughly ऐसा होता है:

```
User App
   ↓
ALSA PCM layer
   ↓
ASoC framework
   ↓
CPU DAI driver (यह file)
   ↓
I2S hardware
   ↓
Codec (WM8960 etc)
```

इस file का काम:

- I2S hardware configure करना
- ALSA PCM callbacks handle करना
- DMA setup करना
- Clock control करना

# 2️⃣ Important Sections of File

### (1) Register Definitions

File के शुरुआत में hardware registers define हैं.

Example:

```
BCM2835_I2S_CS_A_REG
BCM2835_I2S_FIFO_A_REG
BCM2835_I2S_MODE_A_REG
```

इनका काम:

| Register | Meaning                 |
| -------- | ----------------------- |
| CS_A     | Control status          |
| FIFO_A   | Audio data buffer       |
| MODE_A   | I2S mode config         |
| RXC_A    | Receive channel config  |
| TXC_A    | Transmit channel config |

👉 मतलब driver इन registers में value लिखकर **I2S controller control करता है**।

# 1️⃣ ALSA Audio Architecture (Simplified)

```
User Application
     │
     │  (aplay / arecord)
     ▼
ALSA PCM Layer
     │
     ▼
ASoC Framework
 ┌───────────────┬───────────────┬───────────────┐
 │ Machine Driver │ CPU DAI Driver │ Codec Driver │
 │ (board logic)  │ (I2S driver)   │ (codec chip) │
 └───────────────┴───────────────┴───────────────┘
        │                │
        │                │
        │<──── I2S BUS ──>│
        │
        ▼
   Audio Codec
        ▼
   Speaker / Mic
```

👉 यहाँ **I2S physical bus** है जो:

```
CPU I2S Controller  ↔  Codec Chip
```

को connect करता है।

# 4️⃣ I2S actually kya carry karta hai

I2S lines:

```
BCLK   → bit clock
LRCLK  → left/right channel
SDATA  → audio data
MCLK   → master clock
```

Data flow:

```
PCM audio samples
        ↓
I2S serial stream
        ↓
Codec DAC
        ↓
Analog audio
```
